# Chunk-index benchmark results, Prompt 11 (release audit)

The production index with its default configuration (`prod-rows4`), rerun with the unchanged harness and budgets ([`budgets.md`](budgets.md)) to confirm that nothing since Prompt 09 regressed.

- **Raw file:** `raw/run-20261002T053049Z-9cc4763f35c0-dirty.jsonl`.
- **What "dirty" means here:** the working tree differed from commit `9cc4763f` only in tests and documentation. Production and benchmark code were unchanged.
- **Conditions:** the same machine and method as Prompt 08 ([`results.md`](results.md) §1), on the ext4 home volume, with a 16 ms median `fsync`.

**A run that does not count.** A first run from a clone under `/tmp` (tmpfs) measured a 0.009 ms `fsync`. That makes durability free, which invalidates B8 and B10, so it was discarded and not committed. Benchmarks must run on the disk the budgets assume.
